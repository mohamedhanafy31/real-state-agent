┌─────────────────────────────────────────────────────────────────────────────┐
│                         INGESTION FLOW (Building Index)                      │
└─────────────────────────────────────────────────────────────────────────────┘

    ┌──────────────────────┐
    │  Documents Upload    │
    │  (PDF, DOCX, TXT, MD)│
    │  → data/raw/         │
    └──────────┬───────────┘
               │
               │ POST /ingest
               ▼
    ┌──────────────────────┐
    │  LangGraph Pipeline  │
    │  (rag_graph/main.py) │
    └──────────┬───────────┘
               │
               │ State: RAGState
               ▼
    ┌─────────────────────────────────────────────────────────────────────┐
    │                    LANGGRAPH NODES (Ingestion)                       │
    └─────────────────────────────────────────────────────────────────────┘
               │
               ├─► [1] load_documents
               │   └─► src/ingestion/loader.py
               │       • PDFLoader
               │       • DOCXLoader
               │       • TXTLoader
               │       • MDLoader
               │       └─► Returns: List[Document]
               │
               ├─► [2] clean_text
               │   └─► src/ingestion/cleaner.py
               │       • Arabic text normalization
               │       • Egyptian dialect handling
               │       • Remove diacritics
               │       • Normalize characters
               │       └─► Returns: Cleaned text
               │
               ├─► [3] chunk_documents
               │   └─► src/ingestion/chunker.py
               │       • Paragraph-based chunking
               │       • Min/Max size: 100/1000 chars
               │       • Overlap: 50 chars
               │       └─► Returns: List[Chunk]
               │
               ├─► [4] embed_chunks
               │   └─► src/embeddings/embedder.py
               │       • AraModernBERTEmbedder
               │       • Model: mohamed2811/Muffakir_Embedding_V2
               │       • Device: CUDA (if available)
               │       • Batch processing
               │       └─► Returns: Embeddings (1024 dim)
               │
               └─► [5] store_embeddings
                   └─► src/vector_store/faiss_store.py
                       • FAISS Index (L2 distance)
                       • Save: data/embeddings/index.faiss
                       • Save: data/embeddings/chunks.pkl
                       └─► Returns: Index path

┌─────────────────────────────────────────────────────────────────────────────┐
│                         STARTUP SEQUENCE                                    │
└─────────────────────────────────────────────────────────────────────────────┘

    1. Load environment variables (.env)
       └─► GEMINI_API_KEY, HOST, PORT, etc.

    2. Initialize logging system
       └─► setup_run_logging()
       └─► Create log files for this run

    3. FastAPI lifespan (startup)
       ├─► Validate Gemini API key
       ├─► Load embedding model
       │   └─► Check cache first
       │   └─► Download if needed (first time)
       │   └─► Load to GPU/CPU
       └─► Ready to accept requests

    4. Web UI loads
       ├─► Check health status
       ├─► Load document list
       └─► Load chat history (if session exists)
